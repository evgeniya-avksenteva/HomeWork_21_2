# Домашнее задание 21_1

## Описание:

Задание 1
С помощью Bootstrap собраны представленные ниже прототипы 
для дальнейшей работы над проектом. 
Результатом работы являются HTML-документы со структурой 
страниц и подключенными к ним Bootstrap-стилями.


Задание 2
На основе получившейся верстки создано простое веб-приложение, 
которое на любой GET-запрос возвращает страницу «Контакты».
